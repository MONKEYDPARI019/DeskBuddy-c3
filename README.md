# DeskBuddy C3

DeskBuddy C3 is a pocket desk companion built on an ESP32-C3 Super Mini: a 0.96" OLED shows an animated face ("Mochi"), a clock and phone notifications, sent from an Android app over Bluetooth LE or WiFi. This repository contains the firmware, the Android app and `deskbuddy`, a command-line tool and installer window for flashing and talking to the board.

```
pip install "git+https://github.com/MONKEYDPARI019/DeskBuddy-C3#subdirectory=tool"
deskbuddy flash
deskbuddy monitor
```
